# Lintel NY — Website v3 Final

Static HTML website for Lintel NY Home Improvement Contracting with Decap CMS.

## Deploy

1. Push to GitHub
2. Connect to Netlify → build command: `bash build.sh`, publish: `.`
3. Enable Identity → Invite only → Enable Git Gateway
4. Set form notification to info@lintelny.com
5. Invite yourself at Identity → Invite users
6. Access CMS at lintelny.com/admin/

## CMS

Add blog posts, projects, and reviews at `/admin/`. Manifests auto-generate on deploy.
