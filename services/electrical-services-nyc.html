Project Phases

How it happens.

01
Assessment
Existing system evaluated. Panel capacity, wire gauge, grounding, code violations documented.
02
Con Edison Application
If panel upgrade required: application filed. 2-6 week scheduling lead time.
03
Rough-In
New wiring pulled through EMT conduit. Boxes set. Panel wired. DOB rough inspection.
04
Finish
Devices installed. All connections torqued and tested. DOB final inspection.
